# Blog Formatting Guide

Use the following syntax to format your blog posts in the Admin Panel.

## 1. Text Styling

| Style | Markdown Syntax | Example | Result |
| :--- | :--- | :--- | :--- |
| **Bold** | `**text**` | `**Outdoor Advertising**` | **Outdoor Advertising** |
| *Italic* | `*text*` | `*Sabah Market*` | *Sabah Market* |
| Strikethrough | `~~text~~` | `~~Old Price~~` | ~~Old Price~~ |

## 2. Headings
Use `#` for headings. The more `#`, the smaller the heading.

```markdown
# Big Title (H1) - Use this for main sections
## Subtitle (H2) - Use this for sub-sections
### Small Title (H3) - Use this for details
```

## 3. Highlighting (The Blue Box)
To create the blue highlight box (like a quote or tip), use the `>` symbol at the start of the line.

**Syntax:**
```markdown
> This is a highlighted tip!
> It grabs the reader's attention.
```

**Result:**
> This is a highlighted tip!
> It grabs the reader's attention.

## 4. Lists

**Bullet Points:**
Use `-` or `*` followed by a space.
```markdown
* Static Billboards
* Digital Screens
* Unipoles
```

**Numbered Lists:**
Use numbers followed by a dot.
```markdown
1. Identify target audience
2. Choose location
3. Design creative
```

## 5. Adding Images
To add an image inside the content:
```markdown
![Image Description](https://example.com/image.jpg)
```

## 6. Links
To add a clickable link:
```markdown
[Click Here](https://eastmymedia.my)
```

---
**Note:** Text color is controlled by the design system to ensure readability and cannot be changed manually.
